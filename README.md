### 实战项目

项目构建了一个8x8栅格机器人导航环境。系统先用BFS为不同机器人位置和目标生成正确的下一步动作标签，然后通过替代梯度训练SNN模仿BFS策略。完成后，正式导航系统不再调用BFS，而是根据中文指令选择目标，将机器人，目标，障碍物编码为脉冲序列，再由训练后的SNN直接预测机器人下一步动作。

#### 1.Language
程序通过关键词解析中文指令，如“前往红色目标”得到RED

#### 2.Vision
使用三个8x8通道表示机器人，目标，障碍物位置，而非摄像头图像识别

#### 3.Action
输出四种离散动作：UP,DOWN, LEFT, RIGHT。输出脉冲发放率最高的神经元所对应的动作选中

#### 4.SNN部分
3×8×8环境状态-192维输入-Linear(192, 64)-64个LIF隐藏神经元-Linear(64, 4)-4个LIF动作神经元

由于脉冲发放函数不可直接求导，训练时使用ATan替代梯度近似其梯度

#### 5.已遇到问题及解决方法
- 训练数据中UP和DOWN标签较多，导致SNN偏向选择上下移动
  解决方法：使用`WeightedRandomSampler`均衡四种动作的训练次数；推理时多次运行SNN并对输出脉冲率取平均

#### 6.后续可改进方向
- 增加并均衡四种动作的训练数据
- 增加地图、起点和目标位置，提高泛化能力
- 调整网络结构和训练参数，提高预测准确率
